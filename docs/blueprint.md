# **App Name**: Product Showcase Pro

## Core Features:

- Company Name Display: Displays the company name prominently at the top of the application.
- Product Image Carousel: Renders a horizontal, automatically scrolling list of product images, limited to 10 products.
- Product Category Menu: Creates a menu of product categories with submenus that appear on hover.
- Company Profile Display: Presents a fixed-height company profile section with an image and truncated text description.
- Product Center: Displays a grid of 20 product cards, each with an image and product name.
- Company Advantages Carousel: Showcases company advantages in an automatically scrolling image carousel.
- Success Stories Section: Displays up to 15 success stories, each with an image and case name.

## Style Guidelines:

- Primary color: White or light gray for a clean background.
- Secondary color: Dark gray or black for text and elements.
- Accent: Teal (#008080) to highlight interactive elements and sections.
- Use a grid-based layout for responsiveness across different screen sizes.
- Employ a clear visual hierarchy to guide the user through the content.
- Use a consistent style of icons throughout the application.
- Subtle animations for transitions and hovers to enhance user experience.

## Original User Request:
Create a React app to showcase products with the following requirements:
Use TypeScript.
Responsive web design, adaptable for both desktop and mobile browsers.
Layout:
Company Name.
Product category menu, which may have submenus. When the mouse hovers over the menu, the submenu (if any) should automatically display.
Product images automatically scroll horizontally, with no more than 10 products displayed in the scroll.
Company profile, displaying a company image and a text description. This section has a fixed height, and if the text content is too long to be fully displayed, it should be truncated with "..." at the end.
Product center, displaying 20 product cards by default. Each card contains an image and the product name.
Company advantages, with each image automatically displayed in a scroll.
Success stories, displaying no more than 15 success stories. Each story includes an image and the name of the case.
